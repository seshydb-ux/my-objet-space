# My Objet Space — 3D 공간 배치 데모

LG 오브제컬렉션 제품 4종과 시연용 가구를 직접 배치해 보는 React Three Fiber 데모입니다. 별도의 백엔드와 데이터베이스 없이 브라우저에서 작동합니다.

## 실행 방법

Node.js 20.19 이상을 준비한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 프로덕션 빌드는 다음 명령으로 확인할 수 있습니다.

```bash
npm run build
npm run preview
```

Vercel에서는 Root Directory를 `my-objet-space-demo`, Framework를 Vite, Build Command를 `npm run build`, Output Directory를 `dist`로 설정합니다. 카메라 미리보기에는 HTTPS 또는 `localhost`와 브라우저의 카메라 권한이 필요합니다. 카메라 없이 사용하는 데모 모드에는 권한이 필요하지 않습니다.

## 시연 흐름

1. 시작 화면에서 6평 원룸·1.5룸·투룸 템플릿을 선택하거나, 방 형태와 실측 크기를 직접 입력할 수 있습니다. `내 공간 스캔하기`에서는 카메라 미리보기 또는 카메라가 필요 없는 데모 모드로 투룸 스캔 시뮬레이션을 체험합니다.
2. 직접 만들 때 가로·세로·높이(mm), 문과 창문의 벽과 위치를 정합니다. 잘못된 치수나 겹치는 개구부는 입력 화면에서 안내합니다.
3. 왼쪽 카탈로그에서 LG 제품 또는 시연용 가구를 `공간에 추가`합니다. 제품을 클릭하면 강조 테두리와 제품 옆 조작 도구가 나타납니다. 빈 공간을 클릭하면 선택이 해제됩니다.
4. 선택한 제품을 드래그하거나 플로팅 도구의 `이동`을 선택한 후 방향키로 옮깁니다. `회전`을 누르면 0~360도 슬라이더와 0·90·180·270도 빠른 선택이 표시됩니다. 오른쪽 패널의 90도 회전 버튼도 사용할 수 있습니다. `치수 보기`는 선택한 제품의 가로·높이·깊이 표시를 켜거나 끕니다.
5. 세탁기 또는 건조기를 선택하고 `직렬 배치`를 누르면 세탁기 위에 건조기가 정렬됩니다. 기존의 미연결 짝 제품이 있으면 재사용하고, 없으면 새로 만듭니다. 조합은 함께 이동·회전·삭제할 수 있고, 빈자리가 있으면 `직렬 배치 해제`로 분리합니다.
6. 외벽, 기본 가구 또는 다른 제품을 1mm보다 많이 침범하면 빨간색으로 표시하며 겹친 위치에도 놓을 수 있습니다. 내부 벽은 이동 경로나 회전 중에 통과하지 못하도록 막으며, 출입구가 충분히 넓으면 통과할 수 있습니다.
7. 상단뷰·사이드뷰·자유 시점을 선택하고, 빈 공간 드래그로 방을 회전하거나 휠로 확대·축소합니다.
8. LG 제품의 `담기` 또는 직렬 조합의 `조합 두 제품 장바구니 담기`로 시연용 장바구니를 사용합니다. 일반 가구는 배치 전용입니다. `공간 변경`은 현재 배치와 장바구니를 유지하며, 새 내부 벽과 겹치는 제품만 벽 밖으로 옮기고 안내합니다.

## 공간 모델의 범위

- 스캔은 실측이 아닌 발표용 시뮬레이션입니다. 기본 결과는 직사각형 투룸 6,200 × 5,200 × 2,400mm(32.2㎡)이며, 내부 벽과 침실문, 현관문, 창문 두 개를 포함합니다. 평면도에서 직사각형 또는 L자형과 크기를 바꾼 뒤 기존 `Scene`과 `Room` 편집기로 이동합니다.
- 스캔 결과와 투룸 템플릿에는 나무 바닥과 커튼, 러그를 배경으로 표시하고, 공간 크기에 맞으면 건조기와 가구를 시연용으로 배치합니다. 가구는 실제 스캔으로 인식한 물건이 아니며 선택·이동·회전·삭제할 수 있습니다. 작은 공간이나 L자형에서는 충돌을 피할 수 없는 가구를 자동으로 생략합니다.
- 카메라 미리보기는 사용자가 선택했을 때만 요청합니다. 권한을 거부하거나 장치를 사용할 수 없어도 데모 모드로 계속할 수 있으며, 스캔 화면을 나가면 카메라 스트림을 종료합니다. 촬영 영상을 공간 치수 계산에 사용하지 않습니다.
- 직접 만들기는 가로·세로 각각 2,400~12,000mm, 높이 2,000~5,000mm입니다. 투룸 스캔 시연 결과는 내부 구조를 위해 가로 4,800mm, 세로 4,200mm 이상이 필요합니다. L자형은 입력 외곽 사각형의 오른쪽 뒤 40% × 40%를 비운 고정 형태입니다. 잘려 나간 부분의 별도 실측 입력은 아직 지원하지 않습니다.
- 문과 창은 지정한 외벽에 시각적인 개구부로 표시합니다. 개구부 폭·높이는 공간 표현을 위한 기본값이며 실측값이 아닙니다. 외벽의 충돌 범위는 유지되므로 문을 통한 반입·반출이나 문 여닫이 동선은 시뮬레이션하지 않습니다.
- 1.5룸과 투룸은 분리벽을 포함한 발표용 개략 템플릿으로, 실제 주택 도면을 뜻하지 않습니다. `기본 공간 복원`은 선택한 방에서 제품 배치를 초기화합니다.

## 제품과 가격 정보

- 제품과 가구는 `src/products.json`을 공통 원본으로 사용합니다. 렌더링과 충돌 계산에 쓰는 미터 단위 값은 `src/products.js`에서 밀리미터를 변환합니다(1m = 1 Three.js 단위). 제품의 3D 모델은 `src/models/`에 분리되어 있습니다.
- [건조기 RG18EN](https://www.lge.co.kr/product/dryers/rg18en): 700 × 990 × 820mm, 도어 열림 시 전체 깊이 1,380mm.
- [세탁기 FX24ENER](https://www.lge.co.kr/product/washing-machines/fx24ener): 700 × 990 × 830mm, 도어 열림 시 전체 깊이 1,410mm.
- [일반냉장고 DL195ME](https://www.lge.co.kr/product/refrigerators/dl195me): 525 × 1,295 × 555mm. 도어 열림 시 깊이는 공식 자료에서 확인되지 않아 표시하지 않습니다.
- [스타일러 SC5GMR80S](https://www.lge.co.kr/product/lg-styler/sc5gmr80s): 600 × 1,965 × 620mm, 도어 열림 시 전체 깊이 1,190mm. 공식 도어 색상은 블랙틴트미러입니다.
- 외관은 공식 GLB가 아닌, 공식 규격 비율의 단순화된 3D 모델입니다. 카탈로그 이미지는 위 LG 공식 페이지의 이미지를 `public/products/`에 저장하여 사용하며, 이미지 원본 URL과 상세 페이지 URL을 제품 데이터에 기록합니다.
- LG 제품 가격은 임의 숫자를 표시하지 않으며 공식 상세 페이지에서 확인하도록 안내합니다.
- 가구는 공간 배치 시연용 모델입니다. 규격과 가격은 실제 판매 정보가 아니며 가격은 `가격 확인`으로 표시합니다.
- 장바구니는 주문, 결제, 재고, LG 계정 또는 LG 공식몰 장바구니와 연동되지 않습니다.
- 직렬 조합의 외곽 표시 700 × 1,980 × 830mm는 두 제품 본체의 폭·깊이 최댓값과 높이 합계입니다. 스태킹 키트와 부품이 포함된 최종 설치 치수가 아니며 두 모델의 실제 직렬 설치 호환성이나 설치 가능 여부는 판정하지 않습니다. LG 공식 설치 상담을 통해 확인해야 합니다.

LG 공식 제품 상세: [트롬 오브제컬렉션 건조기 RG18EN](https://www.lge.co.kr/product/dryers/rg18en)

## 판정 범위

충돌은 회전한 제품의 직사각형 바닥 면적과 외벽·내부 구획벽·가구의 경계를 비교합니다. 1mm 이내 접촉은 겹침으로 표시하지 않습니다. 치수 보기를 켰을 때 공식 문 열림 깊이가 확인된 제품은 본체 전방의 깊이 차이만 반투명하게 표시합니다. 이 영역은 깊이 참고용이며 실제 도어 궤적이나 설치 여유 공간이 아니고 충돌 판정에도 포함하지 않습니다. 설치 이격 거리, 전원·배수, 반입 경로는 판정하지 않으며 겹침이 없어도 실제 설치 가능 여부를 판단할 수 없습니다.

## 향후 공간 스캔 연결 구조

카메라는 선택적인 미리보기용이며 실제 AI·LiDAR 측정은 구현하지 않았습니다. 향후에는 별도의 스캔 어댑터가 기기별 센서 입력과 권한을 처리하고, 측정 결과를 정규화한 방 모델로 변환해 검증 후 편집기로 전달할 수 있습니다. 변환 결과에는 단위(m), 좌표계, 벽 꼭짓점, 개구부·높이와 측정 불확도를 포함해야 하며 사용자가 편집 전에 확인·수정할 수 있어야 합니다. 현재 편집기는 직사각형 및 고정 비율 L자형만 지원하므로, 임의 다각형·여러 방·불규칙한 벽을 받으려면 바닥 메시와 충돌 계산을 함께 확장해야 합니다.
